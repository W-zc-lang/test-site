如何做一个能被别人访问的网站

用 GitHub Pages 免费部署 · 零基础也能照做

这篇教程教你从零做一个网页，并部署到互联网上，让任何人都能打开。全程免费，不需要买服务器。

一、准备工具

  • 一台电脑（Windows / macOS 均可）
  • 一个 GitHub 账号（免费注册）
  • 一个文本编辑器（记事本都行，推荐 VS Code）
  • GitHub CLI（可选，用来在命令行登录和建仓库）

二、写你的网站

网站最基础的三件套：HTML（内容）、CSS（样式）、JS（交互）。新手先写一个 index.html 就够了。新建文件 index.html，粘贴下面这段：

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>我的第一个网站</title>
</head>
<body>
  <h1>你好，世界！</h1>
  <p>这是我的第一个网站。</p>
</body>
</html>

保存后双击用浏览器打开，就能看到你的页面（此时只有你自己能看到）。

三、部署到 GitHub Pages（关键一步）

想让别人也能访问，必须把文件放到联网的服务器上。GitHub Pages 免费提供这个服务。

方式 A：命令行（推荐，可自动化）

  1. 安装并登录 GitHub CLI：gh auth login（浏览器授权一次）。
  2. 在网站文件夹里初始化并建仓库推送： 
    git init -b main
git add -A
git commit -m "first site"
gh repo create 你的仓库名 --public --source=. --remote=origin --push
  3. 开启 Pages：仓库 Settings → Pages，Source 选 Deploy from a branch，Branch 选 main，文件夹选 / (root)，Save。
  4. 等约 1–2 分钟，访问 https://你的用户名.github.io/仓库名/ 即可。

方式 B：网页操作（不想用命令行）

  1. 在 github.com 新建一个仓库（选 Public）。
  2. 把 index.html 直接拖到仓库的 "Add file" 上传并提交。
  3. 同样在 Settings → Pages 开启，选 main 分支根目录。
小提示：部署后浏览器若显示旧页面，按 Ctrl + F5 强制刷新即可（GitHub Pages 有缓存）。

四、加一个下载链接

想让访客下载文件，把文件（如 sample.txt）放进同一目录，再加一个带 download 属性的链接：

<a href="sample.txt" download>下载示例文件</a>

download 会让浏览器直接下载，而不是打开文件。

五、常见问题

要花钱吗？

不用。GitHub Pages 基础托管免费，部署后直接拿到可访问网址。只有想买自己的域名（如 你的名字.com，约几十块/年）时才花钱，而且不是必须。

别人怎么访问？

把 https://你的用户名.github.io/仓库名/ 这个网址发给谁都行，他们浏览器一输就能打开。

本教程本身也托管在 GitHub Pages 上，源码开放可随意参考。
