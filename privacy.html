隐私政策

最后更新：2026-08-18

本页说明 免费AI工具实测库 如何处理访客数据。本站为静态网站，立场是"尽量不收集"。

1. 我们收集什么

• 你主动提供的信息：仅当你通过邮箱 / GitHub 主动联系我们时，才会收到你自愿填写的内容。

• 本站不直接收集：我们不要求注册、不收集姓名、不收集表单数据。

2. Cookie 与分析

• 当前版本未部署本站自有的追踪 Cookie 或访问统计脚本。

• 网站托管在 GitHub Pages，GitHub 作为平台方可能记录基础访问日志（如 IP、User-Agent），受其隐私政策约束。

3. 第三方广告与数据用途

• 当前版本未投放任何第三方广告（含 Google AdSense 等）。

• 若未来启用广告或分析工具，相关方（如 Google 及合作广告商）可能使用 Cookie 投放个性化广告。届时本政策会更新，并明确告知数据用途与退出方式。

4. 外部链接

本站指向各 AI 工具官网及视频/图文平台的链接为第三方站点，其数据实践由对方负责，请参考对应隐私政策。

5. 你的权利

你可随时通过 联系页 询问我们持有你的哪些信息，或要求我们删除你主动提供的内容。

6. 政策变更

本政策可能随站点功能调整更新，重大变更会在本页标注更新日期。
